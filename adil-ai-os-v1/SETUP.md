# Setup

## Local
- Install Node.js 18+
- Run `npm install`
- Copy `.env.example` to `.env`
- Add your WhatsApp number in international format, numbers only or with +
- Change `ADMIN_KEY`
- Run `npm start`

## GitHub
Upload the complete contents of this project to the repository root. GitHub stores the code, but GitHub Pages cannot execute the Node backend.

## Hosting
Connect the GitHub repository to a Node-compatible deployment platform. Add the same environment variables there. Once deployed, the frontend and `/api/*` routes work together.
